# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly by emailing the maintainer or opening an issue on the [GitHub Issues](https://github.com/joaquinpiedracueva/menubar-dock/issues) page.

## Permissions

MenuBarDock requires **Accessibility** access to read notification badge counts from the Dock. It does not collect, transmit, or store any user data.
